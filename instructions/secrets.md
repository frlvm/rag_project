# Секреты и переменные окружения

1. Настройки, зависящие от окружения, вынесены из `settings.py` в переменные окружения.
2. Django получает их через `os.getenv()`, поэтому значения не записаны прямо в Python-коде.
3. Локальные значения хранятся в файле `.env` рядом с Compose-файлом.
4. К чувствительным значениям относятся `DJANGO_SECRET_KEY`, `GIGACHAT_CREDENTIALS` и пароль PostgreSQL.
5. Адреса сервисов, порты, `DEBUG` и параметры RAG также находятся в `.env`, хотя секретами не являются.
6. Файл `.env` добавлен в `.gitignore`, чтобы Git не отправлял его в удалённый репозиторий.
7. Маска `.env*` добавлена в `.dockerignore`, чтобы файлы окружения не попадали в backend-образ.
8. В репозитории хранится `.env.example` со списком необходимых переменных и примерными значениями.
9. Перед первым запуском разработчик создаёт свой `.env` на основе `.env.example`.
10. Docker Compose передаёт переменные из `.env` контейнерам Django и PostgreSQL во время запуска.
