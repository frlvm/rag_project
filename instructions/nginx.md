# Настройка Nginx

1. Nginx добавлен в Compose как отдельный контейнер перед Django.
2. Для него используется официальный Docker-образ Nginx.
3. Конфигурация сайта хранится в репозитории в `nginx/conf.d/rag_project.conf`.
4. Compose подключает этот файл вместо `/etc/nginx/conf.d/default.conf` внутри контейнера.
5. Конфигурация монтируется только для чтения, чтобы контейнер не изменял файл в репозитории.
6. Nginx слушает порт `80` внутри контейнера, а на локальном компьютере доступен через `localhost:8080`.
7. `server_name rag_project` выбирает блок настроек, но сам по себе не создаёт доменное имя.
8. Запросы с путём `/` и другими динамическими адресами обрабатывает блок `location /`.
9. Эти запросы передаются в Gunicorn по внутреннему адресу `http://django:8000`.
10. Запросы с путём `/static/` обрабатываются отдельно и не передаются в Django.
11. Django собирает CSS, JavaScript и изображения командой `collectstatic` в каталог `/data/static`.
12. Общий bind mount связывает этот каталог с хостом и каталогом статики внутри Nginx.
13. Nginx читает собранные файлы через `alias`, поэтому корректно оформляется и стандартная админка Django.
14. После изменения конфигурации её можно проверить внутри контейнера командой `nginx -t`.
15. Текущая схема рассчитана на localhost, а перед сервером понадобятся реальный домен, HTTPS и корректные proxy-заголовки.
